# Investment Research Retrieval & NLP

**Context:** Financial research and portfolio analysis at BlackRock  
**Focus:** Financial NLP, retrieval-augmented generation, model evaluation, and production ML

## Problem

Analysts work across filings, reports, research records, and earnings-call transcripts. The work involved making this information easier to search and analyze while improving risk signals and model delivery.

## Approach

- Used Python and SQL to analyze portfolio and market datasets and support predictive modeling.
- Applied XGBoost and model validation to improve risk-signal accuracy and reduce model error.
- Used PyTorch, Transformers, and NLP for financial research classification and earnings-call analysis.
- Developed retrieval-augmented workflows with LangChain and vector databases to surface source material for review.
- Supported production workflows with MLflow and AWS SageMaker.

## Reported outcomes

- Risk-signal accuracy improved by **18%**.
- Model error decreased by **16%** on validation benchmarks.
- Analysis identified **$2.4M in potential optimization opportunities**.
- Model deployment cycle time decreased by **28%**.

## Technology

Python, SQL, XGBoost, PyTorch, Transformers, NLP, LangChain, vector databases, MLflow, AWS SageMaker.
