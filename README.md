# Rupa Uppin Portfolio

AI/ML portfolio highlighting applied machine learning, Generative AI, and production data systems.

**Live portfolio:** [transcendent-bunny-9cae99.netlify.app](https://transcendent-bunny-9cae99.netlify.app/)

The site covers three areas of work:

- Investment research copilot with retrieval-augmented generation, financial NLP, model evaluation, and production workflows.
- Telecom churn prediction using behavioral features, boosted trees, complaint classification, and sequence modeling.
- Enterprise backup and license-renewal analytics using SQL, Python, BI dashboards, and statistical analysis.

Project cards expand to show implementation details and reported outcomes. Estimated or attribution-dependent metrics are labeled accordingly.

## Stack

React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Three.js.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
